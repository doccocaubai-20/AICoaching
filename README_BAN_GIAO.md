# Bàn giao dự án CalisCoaching

- `PLAN_MVP.md`: kế hoạch hiện tại lấy hồ sơ và tương tác AI làm trung tâm, với nhật ký nhiều hoạt động và nội dung calisthenics minh họa.
- `PROMPT_AGENT_MVP.md`: prompt giao agent, phụ thuộc, ranh giới và tiêu chí bàn giao.
- `BAN_GIAO_A_SANG_B.md`: trạng thái nền A sau khi sửa, giao diện dữ liệu và prompt giao agent B.
- `BAN_GIAO_B.md`: báo cáo của agent B (hồ sơ, dashboard).
- `BAN_GIAO_A_SANG_C.md`: giao diện dữ liệu hoạt động, quy tắc chống trùng/múi giờ và prompt giao agent C.
- `BAN_GIAO_C.md`: báo cáo của agent C (nhật ký hoạt động).
- `BAN_GIAO_A_SANG_D.md`: dữ liệu buổi tập minh họa, ghi kết quả chống trùng, quy tắc xem lại lịch và prompt giao agent D.
- `BAN_GIAO_D.md`: báo cáo của agent D (buổi tập minh họa, quy tắc xem lại lịch).
- `BAN_GIAO_A_SANG_E.md`: quyền bảng AI, đồng ý, nhà cung cấp/model, an toàn prompt và prompt giao agent E.
- `BAN_GIAO_E.md`: báo cáo của agent E (tương tác AI, tóm tắt, hỏi đáp, phân tích xu hướng, khắc phục sau rà soát).
- `BAN_GIAO_F.md`: báo cáo của agent F (tích hợp toàn diện, nghiệm thu rà soát E, kiểm định smoke test và kiểm thử end-to-end).
- `BAN_GIAO_HO_SO_SUC_KHOE_V2.md`: báo cáo triển khai và bàn giao tính năng Hồ sơ Sức khỏe Cá nhân V2 (Migration 6, Contracts, Server Actions, UI 5 khu vực, Live Workout Companion và kiểm thử tự động).
- `AI_Coaching_de_xuat_y_tuong.md`: đề xuất ý tưởng trước đó; có thể còn nội dung về HLV ở giai đoạn đầu, cần cập nhật nếu sử dụng theo định hướng mới.
- `QR_ho_so_doi_chieu_san_pham.md`: đối chiếu sản phẩm có hồ sơ và QR.
- Các báo cáo cũ cung cấp bối cảnh; phạm vi và ưu tiên MVP hiện hành theo PLAN_MVP.md.

Đã có nền A (Next.js + Supabase, xem README.md); thời hạn thi, quỹ giờ, nhà cung cấp AI và quy mô pilot chưa xác nhận. HLV, chia sẻ hồ sơ và QR là hướng phát triển sau; pilot trải nghiệm hồ sơ/AI không phụ thuộc HLV. Nội dung tập chưa có căn cứ chỉ dùng minh họa.
